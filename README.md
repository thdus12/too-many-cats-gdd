# 고양이가 너무 많아! — 기획서 게시본

`index.html` 은 **생성물이다.** 여기서 직접 고치지 않는다.

```
thdus12/too-many-cats (비공개)
  docs/GDD.md                ← 원본. 여기만 손으로 고친다
        │ tools/build-gdd-html.py
        ↓
  docs/gdd.html
        │ 복사
        ↓
thdus12/too-many-cats-gdd (공개)
  index.html                 ← GitHub Pages 가 서빙
```

이 저장소에는 기획서 문서만 있다. 소스 코드와 커밋 기록은 비공개 저장소에 있다.

읽는 곳: https://thdus12.github.io/too-many-cats-gdd/
